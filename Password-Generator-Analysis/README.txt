To obtain the data for generated passwords run each of the python scripts found within the password_generators folder. You will need to install selenium and the chrome extension for it. This will allow the automated webcrawler to interact with the website. Data collection for manytools and rndgen was done manually.

Once the data collection is finished put all of the password files into the generated_passwords folder and then run passwords_data_stat.py

The resulting table and csv file will be placed in a folder.
