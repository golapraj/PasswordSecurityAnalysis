**Password Security Analysis**  
Large-scale analysis of web password creation mechanisms.  
The project has several components:  
1. Web-Password-Policy-Collector: Collects and analyzes password-policy information from website signup pages.  
2. Password-Generator-Analysis: Generates password datasets using multiple password generators and analyzes them.  
3. Password-Policy-Analysis: Analyzes policy-induced transformations of breached passwords.  
4. Password-Classifier: Classifying Password using XGBoost, SVM, CNN-BiLSTM.
